# Care Ready

Care Ready is a mobile web prototype for family dementia-care handovers. It helps the current caregiver share daily tasks, item-specific guidance and recent changes with the next caregiver.

## Prototype features

- Daily and weekly care schedules
- Task completion records with caregiver names and times
- NFC-linked pages for medication and a water bottle
- Care recipient profile and daily habits
- Handover updates and unfinished-task review
- Multi-caregiver handover planning with an expected time
- Reversible takeover confirmation and handover history

## Run locally

Open `index.html` in a browser, or serve the repository folder locally:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## NFC prototype links

- Medication: `#item-medication`
- Water bottle: `#item-water`

The prototype uses demonstration care and medication information. Replace it with verified information before any real care use.
